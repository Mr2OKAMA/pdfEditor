# PDF ビューア＆エディタ（Edge拡張機能）

PDF.js と pdf-lib を同梱した、完全オフライン動作の Manifest V3 拡張機能です。

## インストール
1. Edge で `edge://extensions` を開き「開発者モード」をオン
2. 「展開して読み込み」でこのフォルダを選択
3. ツールバーのアイコンをクリック → ビューアが開きます
   - リンク/ページの右クリック →「PDFエディタで開く」でURLのPDFも開けます
   - ローカルファイルは「開く」かドラッグ＆ドロップ

## 機能
- 表示・ズーム
- ハイライト、手書き、四角、テキスト（日本語可）、画像/署名の挿入、移動・削除・元に戻す
- ページ回転/削除/移動/白紙挿入、PDF結合、ページ抽出
- 複数PDFをタブで同時に開く（ドラッグ＆ドロップ/複数選択対応）
- 他タブのPDFから指定ページを現在のPDFへ挿入
- 透かし、ページ番号
- 保存時に注釈をPDFへ書き込み（Ctrl+S）

## 制限
既存テキストの直接編集、OCR、暗号化、電子署名(PAdES)は未対応です。
